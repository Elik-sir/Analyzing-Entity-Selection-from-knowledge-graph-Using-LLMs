## Логика раздела

Основной текст включает три рисунка и две таблицы. Они последовательно показывают:

1. Какие графовые семейства труднее и как их профили меняются при соседних дистракторах.
2. Как качество выбора связано с количеством узлов внутри каждого семейства и доступностью отношений.
3. Какие ошибки сохраняются при явных отношениях.
4. Как контролируемые изменения evidence влияют на результаты.

Перенос закономерностей из Tool Selection задаёт мотивацию. Структура, размер и условия предъявления evidence составляют основу эмпирического анализа. Сопоставление с Tool Selection и интерпретация различий завершают Discussion.

## Рисунок 1. Структурные профили выбора при явных отношениях

Предлагаемое название: **Entity-selection profiles across directed graph motifs**.

**Визуализация:** три панели, по одной на модель. По горизонтали — мотивы; по вертикали — exact set match. Для каждого мотива два столбца: disconnected и adjacent distractors.

**Фиксированное представление:** triples на source-карточках. Использовать проверенные controlled-пары; точные селекторы disconnected/adjacent брать из архива.

**Группировка:** пять мотивов с шестью узлами составляют основной блок. Rhombus и hourglass показать отдельным блоком с явными отметками размеров.

**Исследовательский вопрос:** какие семейства трудны при сопоставимом числе узлов и насколько их профили устойчивы к соседним дистракторам?

**Интерпретация:** exact match показывает полное совпадение выбранного множества с reference. Различия семейств являются описательными: одновременно меняются семантика запроса, направления и типы отношений, а не только топология.

## Рисунок 2. Зависимость выбора от количества узлов

Предлагаемое название: **Selection recall across target-subgraph sizes and evidence conditions**.

**Визуализация:** сетка линейных графиков. Строки — три модели; столбцы — chain, star-in, star-out, tree-in и tree-out. По горизонтали — число узлов целевого подграфа; по вертикали — mean per-task recall. Две линии: Raw и Raw+E.

**Данные:** Full Braw/Raw+E, по 100 запланированных задач на доступную размерную ячейку и модель. Rhombus и hourglass не включать в размерные траектории.

**Исследовательский вопрос:** как размерные профили различаются между семействами и моделями и как меняются после добавления явных отношений?

**Обязательные уточнения:**

- Разные размеры представлены разными задачами; это не парное расширение одного графа.
- При фиксированном пуле из 25 кандидатов рост reference меняет долю целевых сущностей и число дистракторов.
- Raw → Raw+E изменяет доступную информацию. Низкий Raw score без проверки достаточности описаний нельзя целиком считать ошибкой рассуждения.
- Не утверждать универсальное монотонное ухудшение с размером.
- Для ограничения ширины макета допустимо разбить сетку на две части в пределах одного рисунка; читаемость важнее формальной компактности.

Аналогичные кривые precision и exact match вынести в приложение. При показе F1 дополнительно учесть изменение аналитических ориентиров с размером: select-all имеет F1 = 2s/(25+s) при reference размера s.

## Рисунок 3. Ошибки, сохраняющиеся при явных отношениях

Предлагаемое название: **Residual selection errors with explicit relational evidence**.

**Визуализация:** составные столбцы по мотивам; отдельные панели по моделям. Условие — source-card triples и disconnected distractors, как базовое условие рисунка 1.

Категории:

- точный выбор;
- только пропуски;
- только лишние сущности;
- одновременно пропуски и лишние сущности;
- невалидный или отсутствующий исход.

**Знаменатель:** все запланированные задачи в ячейке. Невалидные исходы сохранять отдельной категорией. Классификацию выполнять по проверенным fp/fn и validity; не интерпретировать отсутствие ответа как установленную ошибку внутреннего рассуждения.

**Исследовательский вопрос:** какие типы ошибок формируют трудность каждого семейства даже при явных отношениях?

**Назначение:** одинаковый exact match может соответствовать разным профилям пропусков и избыточного выбора. Эти категории характеризуют выход модели, но не устанавливают внутренний механизм ошибок.

Разбор пропусков по ролям узлов добавлять только после отдельной проверки соответствующего анализа. Графовый reference не означает, что каждая карточка незаменима для конечного ответа.

## Таблица 2. Основные контролируемые контрасты

Предлагаемое название: **Paired effects of evidence availability, distractors, and representation**.

| Контраст | Показатели | Назначение |
|---|---|---|
| Raw → Raw+E | Δ recall, Δ exact match | Изменение доступности отношений |
| Disconnected → adjacent при triples | Δ recall, Δ exact match | Структурные дистракторы при явных triples |
| Disconnected → adjacent при templated text | Δ recall, Δ exact match | Дистракторы при другом контролируемом представлении |
| Triples → templated text при фиксированных фактах | Δ recall, Δ exact match | Изменение представления доступных отношений |

Показывать результаты отдельно для трёх моделей. Для encoding-контраста явно зафиксировать размещение отношений и тип дистракторов; альтернативный noise-уровень можно оставить в приложении. Указать число пар, направление разности и способ усреднения. По возможности дать исходное среднее вместе с разностью, чтобы эффект имел понятный масштаб.

Использовать только интервалы, рассчитанные для соответствующей метрики, популяции и заявленного семейства сравнений. Интервалы для F1 нельзя переносить на recall. Если нужные интервалы ещё не рассчитаны, оставить описательные оценки либо сначала зафиксировать план ограниченного offline-анализа.

В основных средних сохранять принятую failure policy: нулевой вклад невалидных/отсутствующих исходов в score при знаменателе всех запланированных задач. Не смешивать этот показатель с оценкой только по valid-парам.

Правила интерпретации:

- Проверять соответствие метрик, references и условий до утверждения переноса.

- Appendix O уже рассматривает KG selection, мотивы, размеры и adjacent distractors; вклад текущей статьи связывать с дополнительными условиями, анализами и результатами.
- Известное участие команды и общую экспериментальную основу описывать прозрачно; отсутствие row-level crosswalk не позволяет утверждать независимость популяций.
- Различия между tool и entity selection мотивируют гипотезы о факторах ошибок, но сами по себе не устанавливают причинный механизм tool selection.
